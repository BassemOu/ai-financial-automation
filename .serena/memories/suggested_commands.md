# Suggested commands

- Install dependencies: `npm --prefix Code install`.
- Start frontend: `npm --prefix Code run dev`.
- Lint: `npm --prefix Code run lint`.
- Production/type-check build: `npm --prefix Code run build`.
- Regenerate requirements PDF: `python3 docs/generate_pdf.py`.
- Optional later Supabase CLI on macOS: `brew install supabase/tap/supabase`, then `supabase login`.
- Serena project configuration and shared memories are committed under `.serena/`; its cache, logs, and `project.local.yml` remain ignored.
