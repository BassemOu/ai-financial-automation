# Core

- **AI Financial Automation** is an AgentAiLearn internship project based on a professor-provided invoice-automation use case.
- Code must be created under `Code/`; it is currently empty. Requirements source: `docs/AI_Financial_Automation_Project_Understanding.md`.
- Goal: replace approximately 24 weekly staff-hours of manual petty-cash and credit-card invoice entry with under two hours/week of exception review.
- Preserve two independent invoice lanes from SharePoint folder routing through tracking-store posting and archival.
- Read `mem:requirements/uc01_invoice_capture` for the authoritative UC-01 flow, expected outcomes, and internship-specific constraints from the supplied images.
- Read `mem:requirements/functional` for the requirement IDs FR-01.1 through FR-01.5 and their acceptance criteria.
- Read `mem:invoice_workflow` for process and requirements, `mem:frontend_scope` for initial UX, `mem:architecture` for domain/integration design, and `mem:delivery` for dependencies and unresolved decisions.
